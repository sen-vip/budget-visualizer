# 📊 학교회계 예산현황판

**에듀파인 엑셀을 불러오면, 복잡한 학교회계 예산을 한눈에 보여주는 웹 도구입니다.**

사업관리카드(현액)로 **내 사업 예산**을 먼저 확인하고, 102-2를 추가하면 **학교 전체 집행현황과 결산 흐름**까지 이어서 볼 수 있습니다.

> 현재 버전 **v0.6.31**  
> 🔗 바로 사용하기: https://budget-visualizer-delta.vercel.app/

---

## 🚀 가장 빠른 사용 방법

처음이라면 **사업관리카드(현액) 파일 하나만** 준비하면 됩니다.

### 1. 사업관리카드(현액) 내려받기

에듀파인에서 다음 경로로 이동합니다.

`학교회계 → 사업관리 → 사업관리카드 → 사업관리카드(현액)`

엑셀 파일을 내려받아 주세요.

### 2. 예산현황판에 파일 불러오기

메인 화면의 **사업관리카드(현액) 불러오기**를 누르거나 파일을 화면에 끌어놓습니다.

파일을 불러오면 바로 다음 내용을 확인할 수 있습니다.

- 내 예산
- 이미 사용하기로 한 금액
- 앞으로 사용할 예정 금액
- 계획까지 반영한 예상 잔액
- 세부사업·세부항목별 잔액
- 돈이 많이 남은 사업

### 3. 학교 전체도 보고 싶다면 102-2 추가하기

메인 하단의 **102-2 불러오기** 영역에 파일을 끌어놓거나 버튼으로 추가합니다.

102-2를 추가하면 **학교 전체 집행현황, 지급 대기 금액, 미원인행위 잔액, 업무추진비, 결산예측**까지 이어서 볼 수 있습니다.

| **102-2 집행실적** | 선택 | 학교 전체 예산, 지급 완료·지급 대기·미원인행위, 업무추진비 |

## 💼 내 사업에서는 이렇게 봅니다

### 💰 계획까지 반영한 예산 흐름

단순 잔액만 보여주지 않습니다.

**내 예산 → 사용 결정액 → 앞으로 사용할 예정 → 예상 잔액** 순서로 보여줘서, 지금 실제로 얼마를 더 쓸 수 있는지 쉽게 확인할 수 있습니다.

### 🔎 세부사업별 예상 잔액

잔액이 많이 남은 사업부터 빠르게 확인할 수 있고, 세부사업과 세부항목까지 내려가며 살펴볼 수 있습니다.

**돈이 많이 남는 사업**에서 항목을 누르면 선택한 세부사업 상세로 자연스럽게 시선이 이동합니다. 요약 금액은 `3억 8,161만원`처럼 읽기 쉬운 단위로 표시하며, 마우스를 올리면 정확한 원 단위 금액도 확인할 수 있습니다.

### 🔁 다른 사업으로 다시 돌아가는 방법

Top10은 특정 사업의 상세를 보고 있어도 **전체 사업 기준으로 계속 유지**됩니다. 그래서 한 사업을 확인한 뒤에도 처음으로 되돌아갈 필요 없이 다른 사업을 이어서 볼 수 있습니다.

1. Top10에서 보고 싶은 사업을 선택합니다.
2. **이 사업 상세 보기**를 누르면 해당 세부사업만 모아봅니다.
3. 상세 화면의 **다른 사업 선택**을 누르면 Top10으로 부드럽게 돌아갑니다.
4. 선택 필터를 풀고 전체 예산을 다시 보려면 **전체 보기**를 누릅니다.

> Top10 선택은 일반 검색창과 별도로 동작합니다. 선택한 사업 이름이 검색어로 자동 입력되지 않습니다.

### 📝 집행계획

앞으로 사용할 금액을 미리 입력하면 **예상 잔액에 바로 반영**됩니다.

입력한 집행예정액은 현재 사용 중인 브라우저에 저장되어 같은 기기에서 다시 확인할 수 있습니다.

## 🏫 학교 전체에서는 이렇게 봅니다

102-2 파일을 추가하면 학교 전체 예산을 다음 상태로 나누어 보여줍니다.

- **지급 완료**: 실제 지급까지 끝난 금액
- **지급 대기**: 원인행위는 되었지만 아직 실제 지급되지 않은 금액
- **미원인행위**: 아직 사용 결정이 이루어지지 않은 예산

정책사업 → 단위사업 → 세부사업 → 세부항목 순으로 내려가며 확인할 수 있고, **지급 대기 금액이나 미원인행위 잔액이 큰 사업**도 따로 모아볼 수 있습니다.

### 🎨 상태 색은 이렇게 읽습니다

102-2 화면의 막대와 범례는 같은 의미에 같은 색을 사용합니다.

- **지급 완료**: 차분한 블루 — 실제 지급까지 끝난 금액
- **지급 대기**: 스틸 틸 — 원인행위 후 아직 지급되지 않은 금액
- **원인행위 전**: 쿨그레이 — 아직 사용 결정 전인 금액

블루 → 스틸 틸 → 쿨그레이로 **지급 완료 → 지급 과정 중 → 아직 사용 결정 전**을 구분합니다. 지급 대기는 경고 상태가 아니므로 주황 대신 차분한 틸을 사용하고, 상단 KPI의 큰 금액은 상태색으로 흐리게 만들지 않고 동일한 진한 글자색으로 표시합니다. 색만 보지 않아도 상태명을 항상 함께 표시하며, 정책사업별 흐름에서도 같은 색 체계를 그대로 사용합니다.

---

## 🧾 업무추진비도 같이 관리할 수 있어요

업무추진비 예산과 현재 잔액을 확인하고, 산출내역별로 앞으로 사용할 예정 금액을 입력할 수 있습니다.

계획을 입력하면 단순 현재 잔액이 아니라 **앞으로의 사용계획까지 반영한 금액**을 확인할 수 있습니다.

---

## 🔮 결산예측은 이렇게 사용합니다

201 세입자료를 연결하면 세입과 세출 흐름을 함께 보면서 **순세계잉여금 예상액**을 계산할 수 있습니다.

결산 전 현재 자료를 기준으로 흐름을 가늠하기 위한 보조 기능이며, 최종 결산자료를 대신하는 기능은 아닙니다.

## 🔒 파일은 어디로 가나요?

**불러온 엑셀 파일은 서버로 업로드하지 않습니다.**

파일 내용은 현재 브라우저에서 직접 읽고 분석합니다.

- 별도 회원가입 없음
- 엑셀 원본 서버 저장 없음
- 별도 데이터베이스 저장 없음
- 집행계획·결산예측 입력값은 브라우저 `localStorage`에 저장될 수 있음

> 공용 PC에서는 사용 후 **자료 비우기 → 저장된 입력값까지 모두 삭제**를 선택해 주세요.  
> 불러온 엑셀뿐 아니라 내 사업 집행계획, 업무추진비 계획·메모, 결산예측 입력값까지 예산현황판이 사용하는 브라우저 저장공간에서 함께 삭제합니다.

## 💡 화면을 볼 때 알아두면 좋아요

### 금액은 읽기 쉽게 표시합니다

큰 금액은 `1억 1,000만원`처럼 읽기 쉬운 단위로 보여주고, 필요한 곳에는 정확한 원 단위 금액도 함께 표시합니다.

### 사용 결정액과 지급액은 다를 수 있습니다

원인행위가 끝났더라도 아직 지급 전이라면 **지급 대기** 금액으로 남을 수 있습니다.

### 집행계획은 실제 에듀파인 자료를 수정하지 않습니다

예산현황판에서 입력한 계획은 **화면에서 예상 잔액을 계산하기 위한 값**입니다. 에듀파인 원본 자료에는 아무 변화가 없습니다.

## 🛠️ 파일이 안 불러와질 때

다음 항목을 먼저 확인해 주세요.

1. 에듀파인에서 내려받은 원본 엑셀인지 확인합니다.
2. 사업관리카드와 102-2 파일을 서로 바꿔 올리지 않았는지 확인합니다.
3. 엑셀의 열 제목이나 시트 구조를 임의로 크게 수정하지 않았는지 확인합니다.
4. 새로고침 후 파일을 다시 불러옵니다.

계속 문제가 있다면 GitHub Issues에 **개인정보를 제거한 화면 캡처와 오류 상황**을 남겨주세요.

- 학교마다 다른 목적·수익자 재원 축약 표기 `(목적)`, `(목)`, `[목]`, `(수익)`, `(수익자)`, `(수)`, `[수]` 등을 함께 인식합니다.
- 재원 표기를 **세부항목과 산출내역**에서 함께 확인해, 표기 위치가 다른 학교 파일도 안정적으로 분류합니다.
- 서로 다른 재원 표기가 한 행에 함께 발견되면 임의 분류하지 않고 **확인 필요**로 안내합니다.
- 업로드 후 학교운영비·목적사업비·수익자부담·확인 필요 건수를 확인할 수 있는 **재원 분류 결과** 진단을 추가했습니다.
