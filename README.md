# 머리날씨 v0.7

편두통 상태와 복약 기록을 가볍게 남기는 정적 웹앱입니다.

## v0.7 변경사항

- 병원 기록 화면을 `복용 중인 약 → 새 진료 기록 → 지난 기록` 순서로 정돈
- 새 진료 입력 폼 접기·펼치기와 입력 중 이탈 경고 추가
- 진료 기록 저장 버튼 위 여백과 모바일 레이아웃 보완
- 지난 진료 기록 상세 접기와 수정·삭제 접근성 이름 추가
- 달력 `이번 달` 이동과 월간 복약 요약 추가
- 로그인 시 기기·계정 기록 병합 방식과 Safari 안내 보완
- 병원용 요약에서 빈 항목을 숨기고 현재·종료 약을 구분

## v0.6 변경사항

- 머리날씨와 상세 기록을 명시적 저장 방식으로 변경
- 약별 `복약 기록 저장` 버튼과 카드 내부 저장 완료 안내 추가
- 저장하지 않은 변경사항이 있을 때 이동 경고 추가
- `어제 기록하기` 바로가기와 과거 날짜 복약 기록 개선
- 약 이름·처방 시작일·복용 기간 입력 검증 추가
- `처방약 없음` 진료 기록 지원
- 선택 버튼의 체크 표시와 `aria-pressed` 접근성 보완
- v0.5 localStorage 기록을 v0.6으로 자동 이전

## 실행

별도 빌드가 필요 없는 정적 사이트입니다. 로컬 웹 서버나 Vercel에서 프로젝트 루트를 그대로 배포하면 됩니다.

Supabase 로그인·동기화를 사용하려면 `supabase-config.js`의 공개용 프로젝트 URL과 Publishable Key를 확인하세요. 브라우저 코드에는 `service_role` 키를 넣으면 안 됩니다.

## 주요 파일

- `index.html`: 화면 구조
- `styles.css`: 반응형 UI
- `app.js`: 기록·복약·달력·동기화 로직
- `supabase-config.js`: 선택 로그인 설정
